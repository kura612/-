# 🚭 Smokefree — モダンな禁煙トラッカー

吸わなかった時間が、そのまま積み上がっていく禁煙アプリ。
React + TypeScript + Vite の SPA で、データはすべて端末のブラウザ (localStorage) にだけ保存されます。サーバーへの送信は一切ありません。

## できること

| 機能 | 内容 |
| --- | --- |
| ⏱ 経過時間カウンタ | 禁煙開始からの日・時・分・秒をリアルタイム表示 |
| 🫁 体の回復タイムライン | 20分 / 8時間 / 24時間 …… 15年まで13段階のマイルストーンと、次の到達までの進捗バー |
| 💰 節約金額・本数 | 1日の本数と1箱の価格から、吸わずに済んだ本数・浮いた金額・取り戻した時間を自動計算 |
| 🧠 クレービング記録 | 「吸いたい」と思った瞬間に強さ(1〜5)ときっかけを記録。乗り切れた率も集計 |
| 📊 傾向の可視化 | 直近7日の件数、時間帯ヒートマップ、きっかけ別ランキング |
| 🌬 3分やり過ごしタイマー | 欲求のピークを呼吸のリズムに合わせて乗り切るタイマー |
| 🌗 ライト / ダークテーマ | OS の設定に自動追従。モバイル幅に最適化されたレイアウト |

## 使い方

```bash
npm install
npm run dev      # 開発サーバー (http://localhost:5173)
npm run build    # dist/ に本番ビルド
npm run preview  # ビルド結果をプレビュー
npm run test     # ロジックのユニットテスト (Vitest)
```

初回起動時に「禁煙を始めた日時 / 1日の本数 / 1箱の本数と価格」を入力すると、以降はその値をもとに集計されます。設定画面から変更・JSON書き出し・全データ削除ができます。

## 構成

```
src/
├── App.tsx              画面切り替え（ホーム / 記録 / 設定）
├── types.ts             Profile・Craving などのデータ型
├── hooks/
│   ├── useAppState.ts   状態管理と localStorage への保存
│   └── useNow.ts        1秒ごとに現在時刻を更新
├── lib/                 画面から独立した計算ロジック（テスト対象）
│   ├── time.ts          経過時間の計算と整形
│   ├── stats.ts         節約金額・本数・取り戻した時間
│   ├── milestones.ts    健康回復マイルストーン
│   ├── cravings.ts      クレービングの集計ときっかけ定義
│   └── storage.ts       localStorage の読み書き
└── components/          UI コンポーネント
```

計算ロジックは `src/lib` に集約し、`src/lib/lib.test.ts` で検証しています。

## 注意

表示している体の回復の目安は、WHO や CDC などが公開している一般的な禁煙後のタイムラインに基づくものです。効果には個人差があり、医療上の助言ではありません。禁煙補助薬や治療については医療機関にご相談ください。
