# ホーム画面ウィジェット（iOS）

`smokefree-widget.js` は [Scriptable](https://scriptable.app/)（App Store で無料）用のウィジェットです。
経過日数・節約金額・次の回復までの進捗を、アプリを開かずにホーム画面で確認できます。

小サイズ・中サイズの2つに対応し、端末のライト／ダーク設定にも追従します。

## なぜ Scriptable なのか

iOS のウィジェットは WidgetKit というネイティブの仕組みでしか作れず、Web アプリ（PWA）からは作れません。
Scriptable は JavaScript でウィジェットを書ける無料アプリで、Xcode も Apple Developer Program（年 $99）も
必要なく導入できます。

本体アプリとデータを同期する仕組みはありませんが、経過日数も節約金額も
**「禁煙開始日時・1日の本数・1箱の本数・1箱の価格」の4つから計算できる**ため、
その4つを設定するだけで本体とまったく同じ数字が出ます。

## 導入手順

1. App Store で **Scriptable** をインストール
2. `smokefree-widget.js` の中身をすべてコピー
   （iPhone だけで完結させるなら、GitHub でファイルを開き **Raw** 表示にしてから全選択・コピー）
3. Scriptable を開き、右上の **+** で新規スクリプトを作成して貼り付け
4. 画面上部のスクリプト名をタップし、**Smokefree** など分かる名前に変更
5. 冒頭の `CONFIG` を自分の値に書き換える（本体アプリの設定画面と同じ値にする）

   ```js
   const CONFIG = {
     quitAt: '2026-08-01T09:00', // 禁煙を始めた日時
     cigarettesPerDay: 20,
     cigarettesPerPack: 20,
     pricePerPack: 600,
   };
   ```

6. 再生ボタン（▶）で表示を確認
7. ホーム画面の何もない所を長押し → 左上の **+** → **Scriptable** → 小 or 中を選んで追加
8. 追加したウィジェットを長押しして **ウィジェットを編集** → **Script** に手順4で付けた名前を選ぶ

## 設定のコツ

- **タップでアプリを開く**: ウィジェットの編集画面で **When Interacting** を **Open URL** にし、
  公開した PWA の URL を入れると、ウィジェットをタップしてアプリが開くようになります。
- **スクリプトを書き換えずに設定する**: ウィジェット編集画面の **Parameter** に
  `2026-08-01T09:00,20,20,600` の形式（開始日時, 1日の本数, 1箱の本数, 1箱の価格）で入力すると、
  `CONFIG` より優先されます。同じスクリプトのまま、複数のウィジェットを別々の設定で置けます。

## 制限

- 更新のタイミングは iOS が決めるため、日付が変わった直後に反映されないことがあります
  （スクリプト側からは、日数が変わる時刻に更新を要求しています）。
- Scriptable を削除すると、このウィジェットも消えます。
- 本体アプリの設定を変えたときは、ウィジェット側も同じ値に直してください。
